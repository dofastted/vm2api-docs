# 总览

`http://<主机>:8787/console/#/overview`

这一页回答三件事：这台机器现在健不健康、账号还能不能被调度、过去一小时服务好不好。它不画多日趋势（那是 [统计](./statistics)），不列每一条请求（那是 [日志](./logs)），也不展开每个账号的 5 小时 / 7 天格子（那是 [用量](./usage)）。

## 你在看什么

- 集群和本机的健康。控制面自己挂了，这一页也打不开，先看 [更新](../upgrade) 里的日志命令。
- 账号是否可调度。不可调度的槽不会出现在新请求的候选里。手动开关在 [虚拟机](./vm)。
- 近一小时的服务质量：成功、失败、以及错误被归成哪几类。点某一类可以到日志里只看那一类。

## 什么时候来这一页

装完或更新完，先看这里，再发测试请求。如果健康是绿的但调用全是 `502 incomplete_response`，不要在总览上找开关。那是槽出口或槽内 DNS，步骤在 [常见问题](../../reference/faq)。

总览上的数字是汇总。要改配额、粘性、人设，去 [设置](../settings)，不要指望在总览上改完就生效。
