# 用量

`http://<主机>:8787/console/#/usage`

每个账号的 5 小时窗口、7 天窗口、并发和费用。总览只告诉你「还能不能调度」，这一页告诉你「还剩多少」。

## 数字从哪来

探测走槽自己的出口，不走控制面直连上游。Setup Token 如果 scope 只有 `user:inference`，官方用量接口会返回 scope 错误，页面上会看到探测失败而不是一个百分比。完整 OAuth scope 才能打官方 `/api/oauth/usage`。

`GET /v1/usage` 给调用方的也是当前 OAuth 账户的 5 小时 / 7 天，单位 `percent_used`。它不改粘性，也不拆粘性。

## 窗口满了以后

调度器在窗口接近上限时不再把新请求放进这个槽。这不是把账号删掉。等窗口滚动，或换一个还有余量的槽。闸门是否生效在 [设置 → 配额](../settings#quota)：5h 闸、7d 闸可以分别关。关掉表示超了仍可能继续送，那是你自己承担上游拒绝。

单个槽的并发和 RPM 可以在虚拟机详情里钉死。钉死的值优先于这一页后面的平台默认。
