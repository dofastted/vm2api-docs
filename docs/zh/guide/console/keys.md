# 密钥

`http://<主机>:8787/console/#/keys`

发给客户端的协议密钥，形如 `sk-vm-…`。它们只能调 `/v1/*`。管理台登录、面板 API，仍然用用户会话或 Master `VM2API_API_KEY`。

## 生成

点 **生成**。明文只在创建时给你一次。库里存的是哈希，之后列表里拿不回原文。当时没复制，就换新，不要来回翻日志找。

## 限额和统计

每把密钥可以单独限制并发和额度。统计弹窗按上海自然日，有今日费用和请求数、花费最高的一天、请求最多的一天、累计 tokens、平均响应、近 7 天成功失败、按模型和按虚拟机的分布。

## 换新

**换新** 立刻让旧值失效，客户端会收到 401。名称、分类、并发、额度、历史统计保留。因为明文不在库里，这是唯一的轮换办法。

## 删除

删除后立刻失效，再用这把 key 也是 401。删除不退已经发生的费用，计费页上的历史还在。

不要把 Master 密钥填进客户端配置。Master 能改面板。协议密钥不能。
