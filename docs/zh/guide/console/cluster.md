# 集群

`http://<主机>:8787/console/#/cluster`

本机是控制台。下面的扩展节点是用 SSH 接进来的其它 VPS，不是本机槽位的第二份列表。槽仍然在 [虚拟机](./vm)。

## 本机

卡片上是这台机器的地址、链路状态、Docker 里正在跑的容器数、槽位数。Docker 数字是「运行中 / 全部」，含出口容器，不只是 `kin-*`。

## 接入一台 VPS

有管理权限时，右上角是 **接入 VPS**。填 SSH 能到达的主机。接上之后，远端 Docker 经这一条 SSH 管理。远端上的槽仍然是一个槽一条出口，规则和本机相同。

## 移除节点

移除会断开 SSH，删掉本机保存的凭证和 Docker 桥。远端机器上的容器继续跑，不会被这条操作删掉。要停远端的槽，先在那台机器上停，再移除节点。

## 终端连不上

集群页的终端和槽详情里的运维终端都是浏览器 WebSocket。页面能开、终端秒断，是 nginx 没把 `Upgrade` 交下去。修反代，不要为了这个重建节点。检查表在产品仓库的 `docs/nginx-shell.md`。
