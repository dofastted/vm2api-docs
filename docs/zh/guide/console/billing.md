# 计费

`http://<主机>:8787/console/#/billing`

花费按两种方式加总，右上角切换：

- **按虚拟机**：再选全部、Claude 或 GPT。Claude 和 GPT 的花费分开算，因为它们不是同一个上游账单。
- **按密钥**：看哪把 `sk-vm-…` 花得多。选按密钥时，平台筛选收起，数字是这把密钥的全部平台。

这里的费用是网关记在请求日志上的用量换算，不是 Anthropic 或 OpenAI 控制台里的发票。对账以官方账单为准。日志没记下的请求不会出现在这里。

要看某一天、某一个模型，用密钥页里的统计，或日志导出。计费页不编辑价格，也没有充值入口。
