# 统计

`http://<主机>:8787/console/#/statistics`

请求量、花费、耗时的趋势，以及按用户、供应商、模型的排行。时间跨度比总览的「近 1 小时」长。它不替代日志：这里没有单条请求的正文。

## 怎么用

- 先看趋势有没有断崖。更新之后调用量掉到零，先确认控制面和槽还在，而不是先改模型目录。
- 排行用来回答「钱花在哪个模型、哪把密钥」。密钥的日明细在 [密钥](./keys) 的统计弹窗里，按上海自然日。
- 正在进行的会话如果出现在这一页的实时面板里，点进会话可以到日志按 session 筛选。

统计读的是已经落库的请求。日志模式设成「关闭」时，这里会空。日志模式在 [设置 → 日志](../settings#logs)。
