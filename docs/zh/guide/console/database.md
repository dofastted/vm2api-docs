# 数据库

`http://<主机>:8787/console/#/database`

给管理员看的运行态，不是备份按钮。备份在 [设置 → 备份](../settings#backup)。

## 三块

- **数据库运行态**：当前快照，标题上有采样时间。
- **提示词缓存**：从 `request_logs` 按小时汇总。日志模式关掉之后，新的小时会是空的。
- **官方用量缓存**：进程内累计。网关没提供这项统计时，页面会写明「未提供用量缓存统计」，数据库快照仍然能看。

这里不能改 SQL，也不能下载整库。要拿走一份能恢复的副本，用备份页创建一条备份再下载。`VM2API_DB_SECRET` 换掉之后，旧库打不开，这一页也会跟着失败。那不是更新脚本会做的事。
