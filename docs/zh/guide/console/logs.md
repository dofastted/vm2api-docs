# 日志

`http://<主机>:8787/console/#/logs`

一行一条请求。可以筛选、导出、点开详情。这是查「这一次为什么失败」的页面，不是看账号窗口的页面。

## 筛选

筛选分成四组：

| 组 | 能筛什么 |
| --- | --- |
| 时间范围 | 日期和时间。可以跳到上一周期、下一周期 |
| 身份 | 管理员能按用户、密钥、供应商、会话筛。非管理员只能按密钥和会话 |
| 请求参数 | 模型、端点、协议 |
| 状态 | 状态码、重试次数、错误类 |

顶部有进行中的会话。点一条会话会把列表收成这个 session。出站 session 和客户端 session 可能不是同一个 id，提示里两行都会写。

错误类可以「只看这一类」，也可以把这一类从列表里屏蔽。屏蔽只影响你现在的视图，不是删除记录。

## 导出

导出可选：跟随当前筛选、全部日志（忽略筛选和屏蔽）、仅错误。仅错误时再选错误类。

## 和设置的关系

记不记日志由 [设置 → 日志](../settings#logs) 的记录模式决定：关闭、普通、Debug。Debug 更吵，排障时再开，不要长期开在生产上。单条请求的交付模式、粘性键，见 [调用 API](../api)。
