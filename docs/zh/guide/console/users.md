# 用户

`http://<主机>:8787/console/#/users`

能登录管理台的人。和 [密钥](./keys) 不是一类东西。用户有会话，密钥没有。

## 角色

| 角色 | 页面上的名字 | 能做什么 |
| --- | --- | --- |
| `admin` | 管理员 | 管理台的全部管理操作，含用户和节点 |
| `super` | 运维 | 运维操作。比租户宽，比管理员窄 |
| `user` | 租户 | 自己的密钥和自己的用量。日志筛选里看不到别人的用户列表 |

安装时的 `VM2API_ADMIN_USER` 是第一个管理员。

## 密码

新密码 8 到 128 位，要输入两次。不一致不能提交。改完，对方现有会话会失效，需要重新登录。最后一列是上次登录时间，没有登录过显示「从未」。

不要把租户提升成管理员来代替发一把 `sk-vm-…`。租户要调模型，给他密钥，不要给他管理台。
