# API 地址

`http://<主机>:8787/console/#/api`

导航上的名字是 **API**。这一页管的是命名的上游地址：下面挂着上游 key 和模型。它不是 [调用 API](../api) 那一页。调用方打的仍是这台网关的 `:8787/v1/...`。

## 删除

删除一个地址会删掉它下面的全部上游 key 和模型。确认框写的就是这件事。删除前先看还有没有槽或路由指着它。

## 和模型目录的差别

[模型](./models) 是客户端能看见的目录。这一页是这些目录项背后的上游入口。只改模型显示名，不会改这里的 key。只删这里的地址，客户端目录里相关模型会一起没掉。
