# vm2api 文档

[vm2api](https://github.com/dofastted/vm2api) 的帮助站：安装、管理台、API 和槽位。

线上：<https://my-project-docs.pages.dev>

```sh
npm install
npm run dev      # http://localhost:5173
npm run build    # docs/.vitepress/dist
npm run deploy   # 构建并上传到 Cloudflare Pages
```

英文是默认语言。简体中文在 `docs/zh/`。产品行为对照 vm2api **1.3.131**。会跟着代码变的字段说明留在产品仓库（`docs/DEPLOY.md`、`docs/API.md`、`docs/PANEL_API.md`）。
